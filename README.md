# Funktionsweise

Fürs ausführen brauchen wir im Terminal im richtigen Ordner diesen Befehl:

```bash
tsc
```

## Schritte zum entwickeln dieses Projekts

1. Ordner Struktur erstellen (Build/JS, SRC)
2. TypeScript initialisieren mit `tsc --init`
3. tsconfig.json anpassen -> siehe dieses Repo
4. index.html erstellen -> Script auf Build/JS/main.js setzen
5. main.ts in SRC Ordner erstellen
6. TypeScript Code schreiben
7. Im Terminal `tsc` ausführen um den Code zu transpilieren
8. index.html im Browser öffnen um das Ergebnis zu sehen

## Nützliche Tipps
- Wenn man nicht weiß was in den Variablen steht, vielleicht `console.log` benutzen
- Wenn man einen Fehler im Terminal sieht, die Zeilennummer im Code nachschauen
- Wenn man einen Fehler hat, die Fehlermeldung **LESEN** und googlen
- Wenn man nicht weiter weiß, jemanden fragen -> Lydia Reiter :)
- Viel Spaß beim Programmieren!
